# 趋势证伪检查（Trend Falsification Check）

在下「随时间变 X」这类结论之前，先问：**这个趋势若不成立，会在数据里留下什么痕迹？**
找不到这样的痕迹 → 你还没验证，只是"看起来像"。本技能给出五类去找痕迹的手段。

## 何时用

- 要写「随着时间，X 上升/下降了」→ 全套走一遍
- 要写「A 组比 B 组高/低」→ 重点查构成分解（第 5 条）
- 要写「X 与 Y 相关」→ 重点查共同驱动因素（伪相关）
- 任何"分组均值随某个维度变化"的结论

**触发词**：验证趋势 / 这个结论可靠吗 / 会不会有偏差 / 换个口径再算 / 幸存者偏差 / 混淆变量 / 因果还是相关。

---

## 核心判据：趋势有三种死法，结构有第四种

一条"随时间演化的趋势"可能不是它看上去的样子，因为：

| 死法 | 本质 | 典型症状 |
|---|---|---|
| **抽样偏差** | 样本不是随机/自然的 | 各期样本量出奇地齐 |
| **指标时序污染** | 指标定义含"当下"，不可跨期比 | 越近的期数值系统性越高 |
| **构成变化** | 均值的群体组成变了，不是个体变了 | 子集趋势与总体背离 |
| **几何伪结构** | 点近似共线，"象限/聚类"是切口造的 | 两个象限恒空、换原点就翻面 |

**只要你没排除这四种，"趋势"或"结构"就还是待证命题。** 下面六条逐一对应。

---

## 检验 1 · 抽样配额检测（最先做，成本最低）

**原理**：真实世界的产出量随时间通常**指数级**变化（人口、发帖、歌曲发行）。
若各期样本量**齐平**，说明是人为配额抽样，**各期之间的"绝对数量比较"全部作废**。

```sql
-- 各期样本量：看是否"整齐得可疑"
SELECT <period>, count(*) AS n
FROM t GROUP BY 1 ORDER BY 1;
```

**判据**：
- 各期 n 相差 < 10% 且覆盖多个数量级的时间跨度 → **配额抽样**，强烈存疑
- 真实的自然样本，早期与晚期常差 10–100 倍

**实例**：某音乐数据集 1920s–2010s 每十年都是 1.9–2.0 万条 →
说明是"每十年等量抽样"，**绝不可**据此说"1920 年代音乐产量与 2010 年代相当"。

**附加指标检验（时序污染）**：若有个指标像"当前热度"，看它是否**随期单调走高**。
若是 → 它是**查询时刻的快照**，不是历史属性，**不可跨期比较**。
```sql
-- 典型：popularity 从早期的 1.3 单调升到晚期的 64.3
-- 这不是"音乐变受欢迎"，是老内容的"当前活跃听众"天然更少
```

## 检验 2 · 锚定对照（用子集隔离混淆）

**原理**：找一个**理论上不受该混淆影响的子集**，看趋势是否还在。

**实例（录音技术史 vs 编曲演化）**：怀疑"原声度下降"是"录音介质变迁"造成：
- 取 **纯器乐** 子集（排除人声编曲差异）
- 若器乐子集**也**同步下降 → 趋势至少部分真实，不全是混杂
- 若只有人声子集降 → 是编曲选择，不是技术

```sql
SELECT <period>,
       avg(<metric>) FILTER (WHERE <subset_condition>) AS 子集,
       avg(<metric>) FILTER (WHERE <control_condition>) AS 对照
FROM t GROUP BY 1 ORDER BY 1;
```

**关键看"两条曲线的分岔点"**：若某期前同步、某期后分岔 →
**两个机制叠加**，前半是共同原因（如技术），后半是子集独有原因（如编曲）。
实例：器乐曲 0.973→0.473 后**稳住**，人声曲继续降到 0.215 →
分岔于 1970s，说明"技术变迁"解释前半，"编曲演化"解释后半。

## 检验 3 · 天然实验：同一对象的多版本跨期比较 ⭐

**这是最强的一击，优先用它。**

**原理**：现实里常有**同一个对象在不同时间被重新制作**的情况
（同一首歌的多个录音版本、同一产品的多次改版、同一用户的重复行为）。
这是天然的对照组：**对象固定，只变时间**。

```sql
-- 找跨多期出现的对象
SELECT <object>, count(*) AS n, count(DISTINCT <period>) AS 期数
FROM t GROUP BY 1 HAVING count(DISTINCT <period>) >= <k>
ORDER BY n DESC LIMIT 20;
```

### 第 0 步（必做）：先验证「同一对象」这个前提本身

**这是本检验最容易被跳过、也最容易翻车的一步。** 前提不成立时，后面所有数字都精致而无意义。

**前提不成立的头号原因：泛用名。** 短标题（overture / intro / home / i love you / summertime / ave maria）
会把**几十首不同的作品**算成"同一个对象"。实测：一个 15 对象的样本里 **5 个（33%）不合格**。

**三个检测指纹**（任何一个命中就该人工看艺人列表）：

| 指纹 | 判据 | 实测命中例 |
|---|---|---|
| **组内极差异常大** | 该对象的指标极差 ≫ 其余对象 | `overture` 0.967 vs 洁净对象最大 0.574 |
| **艺人跨流派** | 同一 key 下艺人横跨古典/说唱/乡村/儿童 | `summertime` = Gershwin 标准 + DJ Jazzy Jeff 说唱 + Kenny Rogers 乡村 |
| **时长分布多峰** | 排序后最大间隙 / 全程 > 0.30 | 6/15 命中（但**有假阴性**，见下） |

```sql
-- 指纹一：组内极差
SELECT <object>, max(<metric>) - min(<metric>) AS 极差, count(*) AS n
FROM t GROUP BY 1 ORDER BY 极差 DESC;
```

⚠️ **时长多峰判据会漏掉"连续铺开"型污染**：`overture` 的时长是**连续铺满** 92–746 秒（罗西尼/威尔第/莫扎特
/百老汇/The Who/Daft Punk 各不相同的作品），最大间隙只占全程 0.211，**判据失效**。
→ 所以**必须配合人工看艺人列表**，不能只靠统计判据自动剔除。

**剔除后的对照实验（必做）**：把污染对象剔掉重跑一遍，看结论是否还成立。
本轮实测（口径 `ICC(1,1)`，观测级）：`acousticness` 的组间份额从 0.153 升到 0.172（**结论更干净**），
而 `instrumentalness` 从 0.151 **掉到 0.007 且不再显著（p=0.229）** ——
说明它在全样本里的"对象效应"**完全是污染伪影**。**不做这一步，就会把伪影写进报告。**

### 第 0.5 步：对象自身的时间下界硬约束（检测日期错标）

若对象有**已知的创作/诞生时间**（作品创作年、产品首发年、公司成立年），它就是一条硬约束：
**任何早于该时间的记录都是错标**。这比"艺人卒年"更硬（不依赖外部名录）。

```sql
SELECT <object>, <period>, count(*)
FROM t
WHERE <period> < (SELECT 创作年 FROM 权威表 WHERE ...)   -- 或直接内联字典
GROUP BY 1,2;
```

**实测命中（2026-09-29）**：17/647 = 2.6% 物理不可能，**全部集中在早期，1950 年后零违例** ——
- Doris Day 的《The Christmas Song》标为 **1932**（该曲 1944 年才写成，Doris Day 当年 10 岁；且她 1945 年才出道）
- **Bing Crosby 的《Silver Bells》标为 1945**（该曲 **1950** 年才写成）—— 演唱者早于作品存在
- Tony Bennett 的《Winter Wonderland》标为 **1936**（Tony 当年 10 岁）

**根因**：日期字段常取自**发行载体**（专辑/合辑）的发行日，旧录音随新合辑再版时会被改写成再版年。
自洽性检查查不出这个坑 —— 实测 `<year> == left(release_date,4)` 命中 647/647，
字段**自己在逻辑上完全自洽**，但语义上不是"录制年"。

### 第 0.9 步：同一录音的跨期重复计数

同一对象的"多个版本"里，可能混着**同一条记录被重复计入不同期**（同一录音出现在两张合辑）。

```sql
-- 同对象 + 同主体 + 同体量（时长/规格差≤1s）→ 疑同一记录
SELECT <object>, <actor>, round(<size>) AS s, count(*) AS cnt,
       count(DISTINCT <period>) AS 跨期数, min(<period>) AS 起, max(<period>) AS 止
FROM t GROUP BY 1,2,3 HAVING count(*) > 1;
```

实测：32 组、超额 34 条，**其中 16 组跨越不同期** → 同一条录音被算进两个时期，**直接污染期均值**。
（例：同一首歌的两个"版本"分别标 1945 与 1994，实为同一条录音。）

**判据**：
- 若这些对象的指标**跟随期数走**（晚期版本呈晚期值）→ 说明指标测的是**时代特征**（支持"技术/时代混淆"）
- 若指标**稳定不变** → 说明测的是**对象自身属性**（趋势是真的）

**实例（决定性）**：《Silent Night》45 个版本跨 8 个十年（1940s–2010s），
全体同期原声度从 0.871 跌到 0.264，而它始终在 **0.63–0.98** 高位震荡 →
**录制于现代的老歌版本依然极度原声** → 原声度反映**编曲选择**，不是录音年代 →
**"技术史混淆"假说被证伪**。

**基准锚点（2026-09-26 固化，报告引用时以此为准）**：

| 十年 | 版本数 | 原声度 | 能量度 | 响度 dB | BPM |
|---|---|---|---|---|---|
| 1940s | 3 | **0.979** | 0.160 | -17.1 | 72.8 |
| 1950s | 10 | 0.949 | 0.188 | -15.3 | 104.5 |
| 1960s | 10 | 0.953 | 0.185 | -16.2 | 95.6 |
| 1970s | 4 | 0.776 | 0.170 | -17.2 | 84.0 |
| 1980s | 6 | 0.634 | 0.234 | -18.1 | 117.4 |
| 1990s | 4 | 0.914 | 0.203 | -16.6 | 131.4 |
| 2000s | 3 | 0.804 | 0.235 | -10.7 | 96.5 |
| 2010s | 5 | **0.954** | 0.105 | -15.3 | 85.9 |

**决定性对比**：同曲原声度 1940s **0.979** → 2010s **0.954**（仅 −0.025），
而全体同期均值 0.871 → 0.264（暴跌 −0.607）。**跨 70 年几乎不变** vs **同期腰斩再腰斩**，
这个反差就是证伪技术史假说的全部力量所在——报告里务必把两行并排呈现。

> ⚠️ 版本数合计 = 45（3+10+10+4+6+4+3+5）。**不要写成 71 版或 73 版**——`White Christmas`
> 才是 73 版。两个数字在早期草稿里被混用过，此处以本表为准。

> ⚠️ **别把这张表读成"稳定"**。上表实为**先跌后回弹**：1940s 0.979 → 1980s **谷 0.634** → 2010s 0.954。
> 正确表述是「**同曲跌幅远小于全体同期跌幅**」，不是「同曲不变」。写成后者，会被"谷"就地反驳。

### 量化升级：用 ICC 把「对象属性」和「时代属性」分开 ⭐

上面是"看形状"，ICC 是"算份额"。**这是天然实验真正的产出形式**，比目测强弱得多。

**单因素方差分解**：因子 = 对象。
- ICC 高 → 该指标是**对象属性**（换对象才变，换时间不变）
- ICC 低 → 该指标是**时代属性**（同一对象也会被时间改写）

> ⚠️⚠️ **最容易踩的坑：`SSB/SST` 不是 ICC，是 η²。**（本技能早期版本就写错并因此报错了数）
> 正确的版本级口径是 `ICC(1,1)`，必须带 **k̄ 校正**（k̄ = 平均每组的观测数）：
>
> ```
> ICC(1,1) = (MSB − MSW) / [ MSB + (k̄ − 1)·MSW ]
>   MSB = SSB/(k−1)   MSW = SSW/(N−k)   k̄ = N/k
> ```
> 漏掉 k̄ 项 → 退化成 η²，**系统性偏高**。

> ⚠️ **第二个坑：算在什么粒度上。** 必须用**观测级**（每条记录）数据算，
> 不能先聚合成 `(对象 × 期)` 的**格均值**再算 —— 格均值会把「同一对象同一期内、
> 不同观测之间」的方差整块抹掉，于是组间方差占比被抬高。

两者叠加起来，误差可以大到离谱。本项目实测（同一份数据、同一批对象）：

| 指标 | η²(格均值) 旧口径 | η²(观测级) | **ICC(1,1) 正确口径** | 旧口径放大倍数 |
|---|---|---|---|---|
| valence | 0.894 | 0.622 | **0.638** | 1.40× |
| energy | 0.734 | 0.394 | **0.406** | 1.81× |
| acousticness | 0.473 | 0.175 | **0.172** | 2.75× |
| instrumentalness | 0.179 | 0.027 | **0.007** | **25.9×** |

**看第三、四列**：观测级 η² 与 ICC(1,1) 几乎相等（差 ≤0.02）。
→ 这说明**造成偏差的是聚合粒度，不是统计量本身**。
这也是自查口径是否算错的最快方法：**同一粒度下 η² ≈ ICC；若两者差很多，就是粒度或 k̄ 出问题了。**

```python
# 无 scipy 也能做：numpy 算 ICC(1,1)（含 k̄ 校正），显著性用标签置换检验
import numpy as np

def icc11(groups):
    """groups = 每个对象的观测数组列表（观测级，别先聚合成格均值）"""
    k = len(groups); N = sum(len(g) for g in groups)
    gm = np.concatenate(groups).mean()
    ssb = sum(len(g) * (g.mean() - gm) ** 2 for g in groups)
    ssw = sum(((g - g.mean()) ** 2).sum() for g in groups)
    msb, msw = ssb / (k - 1), ssw / (N - k)
    kbar = N / k                                   # ⭐ 漏了它就成了 η²
    return (msb - msw) / (msb + (kbar - 1) * msw)

def eta2(groups):                                  # 只用来做「口径自检」：应与 icc11 接近
    gm = np.concatenate(groups).mean()
    return (sum(len(g) * (g.mean() - gm) ** 2 for g in groups)
            / sum(((g - gm) ** 2).sum() for g in groups))

def perm_p(groups, stat, n_perm=5000, seed=7):     # 置换检验比 F 分布查表更稳健
    allv = np.concatenate(groups); sizes = [len(g) for g in groups]
    obs = stat(groups); rng = np.random.default_rng(seed); cnt = 0
    for _ in range(n_perm):
        p = rng.permutation(allv); gs, i = [], 0
        for s in sizes:
            gs.append(p[i:i + s]); i += s
        cnt += stat(gs) >= obs
    return (cnt + 1) / (n_perm + 1)

# 自检：icc11(g) 与 eta2(g) 应当接近；差得远 → 粒度或 k̄ 有问题
```

**实测（口径：`ICC(1,1)`，观测级 = 单条版本记录，k̄ = 43.6；置换 p，n_perm=5000）**：

| 指标 | 全样本池（15 对象 / 647 条） | **洁净池（10 对象 / 436 条）** | 判读 |
|---|---|---|---|
| valence（情绪基调） | 0.564 | **0.638** | **对象属性** —— 圣诞歌永远欢快，谁唱都一样 |
| energy | 0.312 | **0.406** | 中性偏对象 |
| acousticness | 0.153 | **0.172** | **时代属性** —— 八成以上方差来自录音年代 |
| instrumentalness | 0.151（p=0.0002） | **0.007（p=0.229 不显著）** | 全样本的"对象效应"是**污染伪影** |

> 剔除污染后 valence/acousticness 都**上升**（0.564→0.638、0.153→0.172）→ 结论更干净；
> 而 instrumentalness **塌到 0.007 且不再显著** → 它原本的"对象效应"完全由 5 个污染对象撑起来。
> **不做剔除这一步，就会把伪影写进报告。**

**一句话结论（可直接抄进报告）**：同一部作品，**「情绪」是它的固有属性，「音色/编制」是时代可以改写的**。
→ 这正是天然实验的价值：它不只验证一条趋势，而是**给每个指标标注了它属于作品还是属于时代**。

### ⚠️ 期均值的样本量陷阱（谷尤其不可信）

天然实验的每一格都是"该对象在该期的均值"，样本量常极小，且**谷所在的格子往往最薄**：

实测：谷格子的版本数中位仅 **3**，15 个对象里 **7 个的谷落在 n≤2 的格子**；
单版本格子 10 个 + 双版本格子 23 个 = **25.6% 的格子 n≤2**。而峰值期平均每格 10.3 版 → 谷期仅 2.5 版。

**应对**：
1. 谷/峰这类单点**必须同时报 n**，图上对 n≤2 的点做**空心/虚线/小半径**降级
2. 换口径复算，确认谷的位置稳定（实测四档口径**全部锁定同一个谷**：0.5668 / 0.5636 / 0.6136 / 0.5838）
3. 若某对象的谷**恰好**在 n=1 的格子里，不要点它的名

### 逐对象符号检验（证明不是被少数对象带节奏）

均值轨迹的回升，可能只由 2–3 个对象贡献。**逐对象算"谷之后是否回升"，做符号检验**：

实测：**回升 12 / 继续下行 0，单侧 p = 0.0002；剔除污染子集后 9/0，p = 0.0020 —— 零反例。**
同时要**主动找那唯一的反例对象**（本轮 `i'll be home for christmas` ρ=+0.40），把它作为图上的"异类"标出来 ——
全是同向的完美结果反而可疑，一个诚实的反例能极大抬高整份报告的可信度。

**注意找反例**：《Summertime》确实跟着年代跌（0.908→0.094）——因为它
**本身被不断重编**。这种"部分对象跟着走"恰恰说明趋势真实：变化的是编曲方式。

> ⚠️ 但《Summertime》同时也是**泛用名重灾区**（Gershwin 标准 + DJ Jazzy Jeff 说唱 + New Kids On The Block + Kenny Chesney 乡村
> 至少 4 首不同的歌）。**"跟着年代跌"有一部分是"不同歌被排到了不同年代"造成的**。
> → 引用它为反例前，必须先过第 0 步的前提校验。

### 因果解释的最后一问：是"技术变强"还是"风格偏好"

即使趋势稳健，**别急着把它解释成技术进步**。实测 1970s–1990s 的崩落对应电声/合成器编制，
2000s 后的回弹对应**复古编制**（大乐队、无伴奏人声、交响、独立民谣）——
这是**审美选择随时代摆动**，不是"录音技术变原声了"。报告里写成前者，就把文化现象误报成了技术现象。

## 检验 4 · 连续 vs 断崖（形态诊断）

**原理**：真实的社会/艺术演化通常是**平滑**的；断崖意味着**采样或流程变化**。

```sql
-- 找最大单期跌幅
SELECT <period>, avg(<metric>) AS m FROM t GROUP BY 1 ORDER BY 1;
-- 逐期差分，找 top-5 跳变
```

**判据**：
- 平滑下滑 → 渐变机制可信
- 单期断崖 → 查该期是否有**流程/构成**变化（如某类样本突然消失）
```sql
-- 断崖期的构成检查
SELECT count(*) FILTER (WHERE <type>='A') AS A,
       count(*) FILTER (WHERE <type>='B') AS B
FROM t WHERE <period> = <断崖期>;
```
**实例**：某年器乐度 0.078→0.016 断崖，同期器乐曲数 219→28 →
不是"音乐突然都有人声"，是**抽样构成变了**。

**基准锚点（2026-09-26 固化）**：该断崖发生在 **2020 年**（器乐度 2019: 0.078 → 2020: 0.016），
器乐曲数 2015 年 219 首 → 2020 年 28 首，而常年区间为 1,700–6,000 首。
**报告处理铁律**：必须**单列说明**，**不得混入主干趋势**——它是数据构成问题，不是音乐现象。
`decade_features` 视图的 `is_partial_decade` 列就是为标记这个不完整十年而设。

## 检验 5 · 构成分解（是真变化还是组成变了）

**原理**：总体均值的变化，可能来自**个体变化**，也可能来自**群体配比变化**。
经典案例：辛普森悖论。

```sql
-- 分组内看趋势，若组内趋势与总体相反 → 辛普森悖论
SELECT <period>, <group>, avg(<metric>)
FROM t GROUP BY 1, 2 ORDER BY 1, 2;
```

判据：若每个子组内部**方向一致且平稳**，但总体趋势更陡 →
总体趋势被**配比变化**放大了，需在报告中分开陈述。

## 检验 6 · 二维象限的真伪：先查共线性，再谈象限 ⭐⭐

**原理**：当有人把一批对象按两个特征投到二维平面、划分四象限并命名时，
最常见的伪结构是——**这些点其实近似共线**。一条斜线穿过平面时，
只会经过**两个对角象限**，另两个**恒空**；而"哪个点落在哪个象限"
完全由**切口位置（原点）**决定，不由数据决定。

**先做这个，再决定要不要象限叙事**：

```python
import numpy as np
pts = np.array([[x1,y1],[x2,y2], ...])      # 各对象的两维坐标
c = np.cov(pts.T)                            # 2x2 协方差
ev = np.linalg.eigvalsh(c)[::-1]             # 降序特征值
print('PC1 解释率 = %.2f%%' % (100*ev[0]/ev.sum()))
r = np.corrcoef(pts[:,0], pts[:,1])[0,1]
print('r = %.4f' % r)
```

**判据**：
- **PC1 ≥ 95%**（或 |r| ≥ 0.95）→ **近似共线，禁用象限叙事**。改讲"沿斜线的位置/排序"。
- PC1 在 60%–95% → 象限可用，但必须做下面的**原点扰动测试**。
- PC1 < 60% → 点真正散布在平面上，象限叙事成立。

### ⭐ 原点扰动测试（决定象限归属是否稳健）

```python
from collections import Counter
grid = [0.20 + 0.02*i for i in range(31)]     # 在合理范围内扫原点
cnt = {k: Counter() for k in keys}
for ox in grid:
    for oy in grid:
        for k, (x, y) in pts.items():
            cnt[k][('HI' if x>=ox else 'LO') + ('HI' if y>=oy else 'LO')] += 1
tot = len(grid)**2
for k, c in cnt.items():
    dom, n = c.most_common(1)[0]
    print('%s  主导=%s 占比 %.1f%%  %s' % (k, dom, 100*n/tot,
          'STABLE' if 100*n/tot >= 95 else ('mostly' if 100*n/tot >= 70 else 'VOLATILE')))
```

**判据**：
- **主导象限占比 < 70% → 该对象的象限归属是 VOLATILE（不稳定）**，
  换个合理原点就翻面，**不可写进结论**。
- 若 **≥ 半数对象 VOLATILE**，则象限框架整体作废。

**实例（2026-09-29，`era_quadrant` 11 个十年）**：
- 11 点 PC1 = **99.54%**、r = −0.9885 → 近似共线
- 原点在 `[0.2,0.8]²` 的 961 个网格点上扫动：**7/11 个十年 VOLATILE**（主导占比仅 35%–69%）
- **症状 1**：中位数原点下 1970s 独占一象限、另一象限空着；且该点的两个坐标**恰好都等于中位数**（双轴同时卡切口）
- **症状 2**：`HI/HI` 与 `LO/LO` 两个象限**恒空**——这是负斜率直线的数学必然，与数据无关
- **症状 3**：固定阈值 0.5/0.5 时反而给出干净的 5:6 二分 →
  **"看起来更合理"的切口是人为选的，不是数据给的**

### ⭐ 共线性本身也要证伪：分段 PCA

**99% 的共线性有两种来源，必须分开**：

```python
# 全样本 PCA 与 分段 PCA 对比
print('全部  :', pca(all_pts))
print('前段  :', pca(pre_pts))     # 例如早期若干点
print('后段  :', pca(post_pts))
```

- **H1（真斜线）**：前段与后段的 PC1 解释率**都高**，点沿直线均匀滑动。
- **H2（坍缩 + 主导）**：**前段 PC1 低**（点在原地小团里乱转）、**后段 PC1 高**（一条长斜线）
  → 全样本的高共线性是**"前段坍缩 + 后段主导"叠加出来的假象**，
  **不等价于"所有对象都在均匀漂移"**。

**实例**：`era_quadrant` 全样本 PC1 = 99.54%，但拆开后——
前段（1920s–1950s，4 点）PC1 仅 **80.59%**、r 仅 **0.582**；
后段（1950s–2020s，7 点）PC1 = **99.72%**、r = **−0.9927**。
且前段覆盖面积仅为后段的 **1/63**。
→ 真实形态是**"前 30 年趴在原地 + 后段一条长斜线"**，不是均匀漂移。

### ⭐ 路径份额表（找断层，比"最大单段"更本质）

```python
segs = [(i, i+1, dist(p[i], p[i+1])) for i in range(len(p)-1)]
tot = sum(s[2] for s in segs)
for a, b, d in sorted(segs, key=lambda s: -s[2]):
    print('%s->%s  %.4f  (%.1f%% of total)' % (a, b, d, 100*d/tot))
```

**关键洞察**：断层常常**不是单段，而是一对相邻段**。
只报"最大单段"会低估断层的集中度。

**实例**：`era_quadrant` 的 1950s→1960s (0.2512) 与 1960s→1970s (0.2536) **几乎等长**，
**合计占 53.8% 总位移** → 正确表述是"1950s 末到 1970s 初，20 年走完全程一半"，
而不是"1970s 突变"。

### ⭐ 两段式轨迹的常用区分：高台 vs 斜线（用面积比）

```python
area_pre  = (max(x[:k])-min(x[:k])) * (max(y[:k])-min(y[:k]))
area_post = (max(x[k:])-min(x[k:])) * (max(y[k:])-min(y[k:]))
print('后段覆盖面积是前段的 %.1f 倍' % (area_post/area_pre))
```

面积比 **> 20 倍** → 前段实为"高台"（对象几乎不动），图上应**"抱团"表示而非连线**
（连成一团黑点反而误导读者以为有轨迹）。

### ⚠️ 两个相关数字别混层（口径事故高发区）

同一批数据常同时给出两个"相关"，**层不同、值不同、不可互换**：

| 数字 | 含义 | 例（`era_quadrant`） |
|---|---|---|
| **层内相关**（视图列 `corr_ac_en`） | 同一期内**个体之间**的相关 | 2000s: **−0.7485** |
| **层间相关**（均值点之间） | **各期均值点之间**的相关 | 全 11 点: **−0.9885** |

两者都真实。**文案必须写清是哪一个**，否则会被当作同一个数误读。

| 症状 | 大概率是 | 反制 |
|---|---|---|
| 各期样本量齐平 | 配额抽样 | 检验 1；禁用绝对量比较 |

## 三个最硬的结论形式

走完全套检验后，结论只应落在这三种形态之一：

1. **趋势成立**（经受了同物异期检验）→ 可写主结论
   > 例：原声→电子迁移真实，非录音技术幻觉（《Silent Night》反证）
2. **趋势成立但有混淆**（部分由子集解释）→ **分段写**，标注哪段归因于何
   > 例：1950–1970 主因是录音技术，1970 后是编曲演化
3. **趋势不成立 / 不可测**（抽样或指标污染）→ **降级为限制声明**，不写洞察
   > 例：跨年代流行度比较在本数据集**不可执行**

## 输出模板（写进报告时）

```
【趋势】<一句话结论>
【成立性判定】成立 / 成立但有混淆 / 不成立
【支持证据】<检验 2/3 的关键数字>
【已排除的干扰】<检验 1/4/5 的检查结果>
【适用边界】<该结论只在什么条件下成立>
【反例】<至少一个不符合趋势的对象及其解释>
```

**最后一条"反例"不可省**：只有正例没有反例的结论，通常是你没找反例。
找到并解释反例，结论才站得住。

## 已固化的基准锚点（2026-09-26，报告引用时逐条对齐）

> 以下数值经用户确认锁定。写报告时**不得重新探索、不得质疑数值、不得引入外部知识覆盖**。

### 物理断点：**1960 年代中期**（不是十年刻度上）

逐年数据显示转折发生在 1965→1970 之间：

```
1960: 原声 0.767  →  1965: 0.610  →  1970: 0.460  →  1980: 0.285
```

**报告必须写「1960 年代中期」，而非「1970 年代」** —— 断点落在十年桶内部，
写成年代标签就是精度错误。

> 注意与检验 2 的分岔点区分：**断点**（原声度开始转折）在 1960s 中期；
> **分岔点**（器乐曲与人声曲两条曲线分开）在 1970s。两者是不同的事件，别混用。

### 主干趋势锚点

| 关系 | 数值 | 解读 |
|---|---|---|
| 原声度 1920s → 2020s | 0.802 → 0.220（降 73%） | 主结论 |
| 原声 ↔ 能量 | r = **−0.749** | 强负相关 |
| 能量 ↔ 响度 | r = **+0.782** | "响度战争"内核 |
| 响度 1920s → 2020s | −16.7 → −6.6 dB | 约 10 dB ≈ 主观响度翻倍 |
| 舞动度 1920s → 2020s | 0.587 → 0.693（10 段中升 8 次） | 最单调的趋势 |
| 原声>0.8 且 能量>0.8 的曲目 | 327 首（0.192%） | 强负相关的反例检验 |

### 三类必须降级处理的干扰

| 干扰 | 锚点 | 处理 |
|---|---|---|
| 配额抽样 | 各十年 n 均落 19,000–20,000（1920s 5,126 / 2020s 2,030 除外） | 跨年代**绝对数量**比较全部作废 |
| `popularity` 时序污染 | 1920s 1.3 → 2020s 64.3 单调升 | **禁止**任何跨年代热度比较 |
| 构成断崖 | 2020 器乐度 0.078→0.016 | **单列**，不得混入趋势 |

### 三条结论的最终形态

1. **成立** — 原声→电子迁移：原声度 0.80→0.22 是真实的音乐制作演化，
   录音技术史只贡献了 1920–1950 的早期噪声，不是主因
   > ⚠️ **2026-09-29 补注（口径分层，非否定）**：全局 0.80→0.22 的单调形态**掩盖了同物子集的谷-回弹结构**。
   > 在同一批曲目的跨期比较里（129 行 / 15 对象），轨迹是 **1940s 0.834 → 1980s 谷 0.567 → 2010s 0.656**，
   > 四档口径一致、符号检验 12/0（p=0.0002）。即：**全局"一路下滑"与同物"先谷后回"并存**——
   > 因为全局均值同时被"新增曲目构成变化"推动。引用结论 1 时**必须标明它是全局口径**，不可直接套到单曲族上。
2. **成立但需分段** — 双机制叠加：1950s–1970s 器乐与人声同降（共同原因，疑录音技术变迁）；
   1970s 后仅人声曲续降（人声曲独有原因，编曲演化）
3. **不成立** — 跨年代流行度比较：在本数据集**不可执行**，降级为限制声明
